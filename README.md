# Healthcare Analytics – EMR Project

## Project Overview

This project focuses on analyzing Electronic Medical Records (EMR) data to generate meaningful healthcare insights and support data-driven decision-making.

## Objectives

* Analyze patient and visit information.
* Evaluate treatment and healthcare utilization patterns.
* Analyze billing, insurance coverage, and patient payments.
* Develop interactive dashboards for healthcare performance monitoring.

## Tools and Technologies

* **Excel:** Data cleaning, validation, and preliminary analysis.
* **SQL:** Data querying, transformations, and analytical reporting.
* **Power BI:** Interactive dashboards and KPI reporting.
* **Tableau:** Visual analytics and interactive dashboards.

## Project Files

* `Excel File.xlsx` – Healthcare dataset.
* `SQL-File.sql` – SQL scripts.
* `Power Bi-Dashboard.pbix` – Power BI dashboard.
* `Tableau-Dashboard.twb` – Tableau workbook.

## Key Analytical Areas

* Patient demographics and registrations.
* Visit types and treatment categories.
* Healthcare utilization and patient trends.
* Billing, insurance coverage, and outstanding payments.

## Project Outcome

The project demonstrates practical data analytics skills, including data preparation, SQL analysis, KPI development, dashboard creation, and communicating insights through visualizations.

## Note

All data shared publicly must be appropriately de-identified and authorized for publication. Replace or remove confidential information before sharing this repository.
